# 排课系统 — 产品设计文档

> 基于 Spring Boot + Vue 的自动排课系统
> 文档版本：v1.0  |  最后更新：2026-09-01

---

## 1. 产品概述

### 1.1 项目背景
本项目是本科毕业设计，目标是实现一个**面向中小学/高校的自动排课系统**，
解决传统手工排课效率低、易冲突的问题。

### 1.2 目标用户

| 角色 | 主要场景 |
|---|---|
| **教务管理员** | 录入基础数据、触发排课、调整冲突、导出课表 |
| **教师** | 查看个人课表 |
| **学生** | 查看班级课表 |

### 1.3 核心价值
- **省时间**：原来 1 周的排课工作，缩短到 1 小时
- **少冲突**：自动检测教师/班级/教室时间冲突
- **易调整**：可视化拖拽调课
- **可复用**：导出 Excel 课表

---

## 2. 用户角色与权限

| 角色 | 权限 |
|---|---|
| 管理员 | 全部操作（增删改查、触发排课、调整） |
| 教师 | 只读：查看个人课表 |
| 学生 | 只读：查看班级课表 |

MVP 阶段**只做管理员**，教师/学生页留接口。

---

## 3. 核心功能模块

### 3.1 基础数据管理（CRUD）

| 模块 | 字段 | 说明 |
|---|---|---|
| 教师 | 编号、姓名、性别、电话、职称、可教课程 | 一对多：教师 ↔ 可教课程 |
| 班级 | 编号、名称、年级、人数 | |
| 课程 | 编号、名称、学分、周学时、类型（必修/选修） | |
| 教室 | 编号、名称、容量、类型（普通/实验室/多媒体） | |
| 时间段 | 第几周、第几节、星期几 | 预置周一~周五 × 8 节 |

### 3.2 排课规则

| 规则 | 说明 |
|---|---|
| 教师不冲突 | 同一教师同一时间只能上一节课 |
| 班级不冲突 | 同一班级同一时间只能上一节课 |
| 教室不冲突 | 同一教室同一时间只能被一个班用 |
| 教室容量 | 班级人数 ≤ 教室容量 |
| 教师可教课程 | 课程的教师必须在教师可教课程列表里 |
| 课程周学时 | 一门课每周排几节 |
| 连排约束 | 同一课程同一班级尽量连排（2 节一起） |

### 3.3 自动排课
- **输入**：教师/班级/课程/教室/时间段 + 排课规则
- **输出**：排课结果（教师 × 时间段 → 课程/班级/教室）
- **算法**：基于**回溯 + 贪心**（先按约束最严的排，再放宽）

### 3.4 手动调课
- 显示当前课表（教师/班级/教室三视角）
- 拖拽单元格交换
- 自动检测冲突并提示

### 3.5 课表展示
- **班级课表**：行=节次，列=星期，单元格=教师+课程
- **教师课表**：同上，视角换成教师
- **教室课表**：同上，视角换成教室
- **导出 Excel**

### 3.6 用户登录
- 账号 + 密码登录
- 角色区分
- MVP 只做管理员登录

## 4. MVP 范围（4 步走）

| 步 | 内容 | 预计 |
|---|---|---|
| **M1** | 项目骨架：后端 + 前端 跑通，能看到登录页 | 0.5 周 |
| **M2** | 登录 + 教师/班级/课程/教室/时间段 CRUD | 1 周 |
| **M3** | 排课规则 + 自动排课 + 课表展示 | 1.5 周 |
| **M4** | 手动调课 + 答辩文档 + 测试 | 1 周 |

**答辩保底**：M2 完成即可演示「基础数据管理」。

## 5. 技术栈

### 5.1 前端
- **框架**：Vue 3 (Composition API)
- **UI 库**：Element Plus
- **构建**：Vite
- **HTTP**：Axios
- **路由**：Vue Router
- **状态**：Pinia

### 5.2 后端
- **框架**：Spring Boot 3.3
- **ORM**：Spring Data JPA
- **数据库**：MySQL 8.0
- **构建**：Maven 3.9
- **JDK**：17
- **依赖注入**：Spring IoC
- **验证**：Jakarta Validation
- **工具**：Lombok

### 5.3 工具链
- **代码仓库**：Git
- **包管理**：Maven（后端）、npm（前端）
- **Maven 镜像**：阿里云（国内加速）
- **数据库客户端**：MySQL Workbench / Navicat
